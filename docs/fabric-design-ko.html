고무 코드를 탄성 밴드에 클립으로 다는 대신, 스트레치 센서를 전도성 원단 조각으로 만들어 밴드에 바로 꿰매어 넣습니다. 더 납작하고, 더 안정적이며, 부품을 붙여 놓은 것이 아니라 하나로 통합된 형태입니다.

감지 원리

코드와 똑같은 원리이고 회로도 동일합니다. 두 접점 라인 사이의 구간이 늘어날수록 원단의 저항이 작아집니다 — 고무 코드와 반대 방향입니다. XIAO는 분배 회로 가운데 지점의 전압을 읽습니다.

바뀌는 것, 그대로인 것

그대로 유지

  • XIAO, IMU, 블루투스 펌웨어
  • 전압 분배 방식과 측정 코드
  • FORM Lab과 계산하는 모든 지표
  • 벨크로 밴드와 센서 파우치

변경

  • 고무 코드 → 꿰매어 넣은 전도성 스트레치 원단
  • 악어 클립·감은 전선 → 전도성 실 두 줄을 접점으로
  • 센서 부위 납땜 → 꿰매거나 압착 접점 (원단은 납땜 불가)
  • 고정 저항 값을 원단에 맞게 다시 선택
  • 신호 방향이 반대: 원단은 늘어날 때 저항이 줄어들어 펌웨어에서 부호를 뒤집음

확정 전에: 벤치 테스트 한 번

원단은 재설계가 아니라 교체이므로, 꿰매기 전에 코드를 검증했던 방식 그대로 검증합니다.

  • 원단을 잘라, 일정 간격으로 임시 접점 라인 두 개를 답니다 (전도성 실이나 포일 테이프).
  • 멀티미터로 쉴 때와 늘렸을 때 저항을 측정합니다 — 코드 세션과 똑같이.
  • 세 가지를 확인합니다: 저항이 뚜렷하게 읽힐 만큼 변하는가, 원래 값으로 돌아오는가, 고무보다 드리프트가 적은가.
  • 고정 저항을 원단의 휴식 저항값 근처로 고른 뒤, FORM Lab으로 컬 세트를 코드 기록과 비교합니다.

테스트로 답할 질문: 얼마나 민감한가, 늘어남 대비 눌림에 얼마나 반응하는가, 꿰매고 착용해도 견디는가. 이 항목들에서 이기면 원단이 v2가 됩니다. 아니면 코드를 유지하고 이건 스케치로 남습니다.
